SHIFA WEBSITE - HOW TO PUBLISH
==============================
Contents
  index.html  the whole website (all pages, styles, animations and logo are inside this one file)
  logo.jpg    the Shifa logo, kept separately for social media profiles etc.

Quick options (all can be free)
  1. Netlify Drop: go to app.netlify.com/drop and drag this folder (or the unzipped folder) onto the page.
  2. Cloudflare Pages: create a Pages project and use "Direct Upload".
  3. GitHub Pages: put index.html in a repository, then Settings > Pages.
  4. Ordinary web hosting: upload index.html into the public_html (or www) folder using the host's File Manager or FTP.

Custom domain
  Buy a domain (e.g. shifawoking.org.uk) from a registrar, then add it in your host's "Domains" settings
  and follow the DNS instructions they show.

Contact form
  The form opens the visitor's email app addressed to info.shifawoking@gmail.com.
  To receive messages directly, use a form service (e.g. Formspree) and ask for help wiring it in.

Before going live, check with Shifa that the phone number, email address and class timetable are current.
